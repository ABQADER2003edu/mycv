## تفاصيل المشروع (Project Info)
This project focuses on accelerating the core arithmetic of Post-Quantum Cryptography (PQC) by implementing optimized NTT, modular arithmetic, and polynomial hardware architectures for Kyber ML-KEM in Verilog HDL on the Vortex GPGPU platform — bridging quantum-resistant security with high-performance hardware acceleration.

## أبرز الإنجازات (Key Achievements)
- تصميم دوائر تسريع الأجهزة (Hardware Acceleration) المتقدمة باستخدام Verilog HDL.
- تحسين العمليات الحسابية المعقدة (NTT, modular arithmetic, polynomial hardware architectures).
- التطبيق المباشر على منصة Vortex GPGPU لبناء أنظمة آمنة ضد التهديدات الكمية.
- العمل في فريق متميز وإدارة الوقت والتسليم بكفاءة عالية تحت ضغط للوصول لنتيجة الامتياز.
