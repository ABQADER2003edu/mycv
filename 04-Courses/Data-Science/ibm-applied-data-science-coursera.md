# IBM Applied Data Science Specialization

- **الاسم الرسمي للكورس/الشهادة:** IBM Applied Data Science Specialization
- **الجهة المنظمة / المنصة:** كورسيرا (Coursera) / IBM
- **المدرب/المدربين:** خبراء ومهندسي بيانات من شركة IBM
- **المساعدين / الـ TAs:** لا يوجد بيانات
- **تاريخ البداية والنهاية:** غير محدد
- **عدد الساعات / المدة الفعلية:** 80 ساعة (80 hrs)
- **التقدير / النتيجة:** مكتمل بنجاح
- **المحتوى الأساسي:**
  - تخصص تطبيقي شامل يركز على تحليل البيانات وتصورها.
  - النمذجة التنبؤية (Predictive Modeling) باستخدام لغة Python.
  - التعامل مع قواعد البيانات واستخدام SQL في استخراج وتحليل البيانات.
  - أدوات ومكتبات Python الأساسية لعلوم البيانات (Pandas, NumPy, Matplotlib, Scikit-learn).
  - منهجية معالجة البيانات الضخمة وبناء نماذج تدعم اتخاذ القرارات وحل المشكلات الواقعية.

- **المشروع/المشاريع اللي عملتها فيه:**
  - تم تنفيذ عدة مشاريع تطبيقية خلال التخصص تعتمد على تحليل بيانات حقيقية، وتنظيفها، وبناء نماذج تنبؤية لتقييم النتائج وعرضها بوضوح للجمهور غير التقني.

- **أصعب حاجة واجهتها فيه وإزاي حليتها:**
  - التعامل مع مجموعات بيانات غير منظمة (Messy Data) وتنظيفها. حليت المشكلة عن طريق التعمق في ميزات مكتبة Pandas واستخدام التعبيرات النمطية (Regex) والبحث الدائم في مصادر الإنترنت.
  
- **أسهل/أمتع جزء:**
  - تصور البيانات (Data Visualization) واستخراج الرؤى (Insights) المباشرة من الأرقام، مما يعطي معنى واضحاً وراء البيانات المعقدة.

- **السكيلز اللي طبقتها فعليًا:** 
  - لغة Python
  - استعلامات SQL
  - تحليل البيانات وتصورها
  
- **حاجات جديدة اتعلمتها ملهاش دخل بالمنهج نفسه:**
  - أهمية السرد القصصي للبيانات (Data Storytelling)، حيث أن النماذج القوية تفقد قيمتها إن لم يتم شرح نتائجها بوضوح للمستفيدين.

- **علاقات/شبكة تواصل استفدت منها:**
  - التفاعل غير المباشر من خلال مجتمعات التعلم والمراجعات (Peer Reviews) على كورسيرا.

- **رابط الشهادة/الإثبات:** 
  - [شهادة تخصص IBM Data Science](https://www.coursera.org/account/accomplishments/specialization/5DPT5N8SRAAS)

- **ملاحظات حرة:**
  - التخصص كان نقطة البداية القوية لي في دمج التحليل الإحصائي مع مهارات البرمجة، وهو ما أثرى تفكيري التقني عموماً.
