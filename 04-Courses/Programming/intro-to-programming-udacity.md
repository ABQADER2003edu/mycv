# Connect - Intro to Programming

- **الاسم الرسمي للكورس/الشهادة:** Connect - Intro to Programming
- **الجهة المنظمة / المنصة:** يوداسيتي (Udacity)
- **المدرب/المدربين:** غير محدد
- **المساعدين / الـ TAs:** غير محدد
- **تاريخ البداية والنهاية:** تاريخ التخرج: 14 يوليو 2019؛ تاريخ البداية غير محدد
- **عدد الساعات / المدة الفعلية:** 109 ساعات وفق صفحة البرنامج
- **التقدير / النتيجة:** مكتمل بنجاح
- **المحتوى الأساسي:**
  - الأسس المنطقية للبرمجة.
  - Python وHTML وCSS وJavaScript.
  - التحكم بالتدفق، الدوال، البرمجة الكائنية، وهياكل البيانات.
  - بناء صفحات الويب والتعامل مع DOM والأحداث.
  - كتابة كود قابل للتطوير وتصحيح الأخطاء.
- **المشاريع الموجودة ضمن المنهج:** Animal Trading Card، Python Text Adventure Game، Rock Paper Scissors باستخدام OOP، وJavaScript Shopping Cart.
- **المشروع/المشاريع اللي عملتها فيه:** بناء تطبيقات ومشاريع صغيرة لترسيخ مفاهيم البرمجة وحل المشكلات.
- **أصعب حاجة واجهتها فيه وإزاي حليتها:** الانتقال من التفكير البشري للمشكلة إلى صياغتها كخوارزمية، وتم التعامل مع ذلك بالتدريب المتكرر وتجربة الأكواد.
- **أسهل/أمتع جزء:** تشغيل الكود بعد تجاوز الأخطاء.
- **السكيلز اللي طبقتها فعليًا:** البرمجة وتطوير البرمجيات، Python، HTML، CSS، JavaScript، OOP، هياكل البيانات، حل المشكلات، وتصحيح الأخطاء.
- **حاجات جديدة اتعلمتها ملهاش دخل بالمنهج نفسه:** الصبر والمثابرة أثناء Debugging وأهمية توثيق الكود.
