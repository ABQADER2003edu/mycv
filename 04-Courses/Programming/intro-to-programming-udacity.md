# Connect - Intro to Programming

- **الاسم الرسمي للكورس/الشهادة:** Connect - Intro to Programming
- **الجهة المنظمة / المنصة:** يوداسيتي (Udacity)
- **المدرب/المدربين:** مدربي يوداسيتي المعتمدين
- **المساعدين / الـ TAs:** مجتمع الطلاب والموجهين بالمنصة
- **تاريخ البداية والنهاية:** غير محدد
- **عدد الساعات / المدة الفعلية:** 109 ساعة (109 hours)
- **التقدير / النتيجة:** مكتمل بنجاح
- **المحتوى الأساسي:**
  - الأسس المنطقية للبرمجة (Logic Foundations).
  - تطوير البرمجيات وبناء التطبيقات خطوة بخطوة.
  - التدرب على كتابة كود نظيف (Clean Code) وقابل للتطوير (Scalable).
  - التعرف على أدوات التطوير ومفاهيم حل المشكلات برمجياً وكفاءة الخوارزميات الأساسية.

- **المشروع/المشاريع اللي عملتها فيه:**
  - بناء مجموعة من التطبيقات والمشاريع الصغيرة لترسيخ مفاهيم البرمجة الكائنية (OOP) وهياكل البيانات الأساسية.

- **أصعب حاجة واجهتها فيه وإزاي حليتها:**
  - فهم كيفية الانتقال من التفكير البشري للمشكلة إلى صياغتها كخوارزمية برمجية تفهمها الآلة. حُلت عن طريق التدريب المكثف على حل المشكلات وتجربة الأكواد بشكل متكرر.
  
- **أسهل/أمتع جزء:**
  - اللحظة التي يتم فيها تشغيل الكود وتجاوز كل الأخطاء (Bug-free execution).

- **السكيلز اللي طبقتها فعليًا:** 
  - البرمجة وتطوير البرمجيات
  - Python (كأساس لاحقاً)
  - حل المشكلات

- **حاجات جديدة اتعلمتها ملهاش دخل بالمنهج نفسه:**
  - الصبر والمثابرة عند التتبع لاكتشاف الأخطاء (Debugging)، وأهمية توثيق الكود لتسهيل الرجوع إليه وتطويره.

- **علاقات/شبكة تواصل استفدت منها:**
  - منتديات الدعم والنقاش الخاصة ببرنامج Udacity Connect.

- **رابط الشهادة/الإثبات:** 
  - [شهادة مقدمة في البرمجة](https://www.udacity.com/certificate/e/195c255a-92b0-11e9-aaea-cbaf6f7b8ca9)
