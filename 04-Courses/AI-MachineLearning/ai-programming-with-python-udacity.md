# AI Programming with Python

- **الاسم الرسمي للكورس/الشهادة:** AI Programming with Python Nanodegree Program
- **الجهة المنظمة / المنصة:** يوداسيتي (Udacity)
- **المدرب/المدربين:** غير محدد في الشهادة
- **المساعدين / الـ TAs:** غير محدد
- **تاريخ البداية والنهاية:** تاريخ التخرج: 20 فبراير 2021؛ تاريخ البداية غير محدد
- **عدد الساعات / المدة الفعلية:** 52 ساعة وفق النسخة المسجلة في الملف؛ تختلف المدة بين إصدارات البرنامج
- **التقدير / النتيجة:** مكتمل بنجاح
- **المحتوى الأساسي:**
  - كتابة أكواد بلغة Python وتطبيقها في مجالات الذكاء الاصطناعي.
  - الأساسيات الرياضية للذكاء الاصطناعي، بما في ذلك الجبر الخطي وحساب التفاضل والتكامل.
  - استخدام NumPy وPandas وMatplotlib لتحليل البيانات وتصورها.
  - بناء وتدريب نماذج تعلم آلي وشبكات عصبية باستخدام PyTorch.
  - التعرف على النماذج المدربة مسبقًا وTransfer Learning.
  - تتضمن إصدارات البرنامج الحديثة موضوعات NLP وTransformers والذكاء الاصطناعي التوليدي، وقد تختلف عن النسخة التي درسها صاحب الشهادة.
- **المشروع/المشاريع اللي عملتها فيه:**
  - تطوير مصنف لصور الزهور (Image Classifier) باستخدام PyTorch وTransfer Learning، وفق المشروع المسجل في تجربة الكورس.
- **أصعب حاجة واجهتها فيه وإزاي حليتها:**
  - الفهم الرياضي لعمليات Backpropagation داخل الشبكات العصبية، وتم التعامل معه بالمراجعة اليدوية للمفاهيم الرياضية والرجوع إلى مراجع إضافية.
- **أسهل/أمتع جزء:**
  - استخدام النماذج الجاهزة (Pre-trained Models) وTransfer Learning.
- **السكيلز اللي طبقتها فعليًا:** Python، NumPy، Pandas، Matplotlib، PyTorch، الذكاء الاصطناعي، الجبر الخطي، وأساسيات الشبكات العصبية.
- **حاجات جديدة اتعلمتها ملهاش دخل بالمنهج نفسه:** تنظيم بنية المشروع والتعامل مع واجهة الأوامر (CLI).
- **علاقات/شبكة تواصل استفدت منها:** مراجعات الكود والتغذية الراجعة ضمن بيئة Udacity.
- **رابط الشهادة/الإثبات:** [شهادة AI Programming with Python](https://www.udacity.com/certificate/e/ac0e4426-2f2d-11eb-926c-c7641132420f)
- **مصادر تفاصيل المنهج:** [صفحة البرنامج الرسمية](https://www.udacity.com/course/ai-programming-python-nanodegree--nd089)، [شرح Udacity للبرنامج](https://www.udacity.com/blog/ai-programming-with-python-in-action/)، [تفاصيل Image Classifier](https://medium.com/udacity/implementing-an-image-classifier-with-pytorch-part-1-cf5444b8e9c9)
