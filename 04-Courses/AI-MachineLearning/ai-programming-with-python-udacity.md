# AI Programming with Python

- **الاسم الرسمي للكورس/الشهادة:** AI Programming with Python
- **الجهة المنظمة / المنصة:** يوداسيتي (Udacity)
- **المدرب/المدربين:** خبراء الذكاء الاصطناعي في يوداسيتي
- **المساعدين / الـ TAs:** مرشدي Udacity (Mentors)
- **تاريخ البداية والنهاية:** غير محدد
- **عدد الساعات / المدة الفعلية:** 52 ساعة (52 hour)
- **التقدير / النتيجة:** مكتمل بنجاح
- **المحتوى الأساسي:**
  - كتابة أكواد متقدمة بلغة بايثون وتطبيقها في مجالات الذكاء الاصطناعي.
  - الأساسيات الرياضية للذكاء الاصطناعي (الجبر الخطي وحساب التفاضل والتكامل).
  - التعرف على مكتبات تعلم الآلة (Machine Learning) وبناء النماذج الأساسية.
  - استخدام مكتبة PyTorch لبناء شبكات عصبية (Neural Networks) بسيطة.
  - أتمتة العمليات وتحسين الأداء لاتخاذ قرارات ذكية ومدعومة بالبيانات.

- **المشروع/المشاريع اللي عملتها فيه:**
  - تطوير مصنف لصور الزهور (Image Classifier) يعتمد على الشبكات العصبية باستخدام PyTorch، وتدريبه على التعرف بدقة على أنواع مختلفة من الصور.

- **أصعب حاجة واجهتها فيه وإزاي حليتها:**
  - الفهم الرياضي العميق لعمليات الـ Backpropagation داخل الشبكات العصبية. حليت الموضوع برسم العمليات الحسابية يدوياً على الورق والرجوع لمراجع خارجية لفهم الجبر الخطي.
  
- **أسهل/أمتع جزء:**
  - استخدام النماذج الجاهزة (Pre-trained models) واستغلال الـ Transfer Learning لرؤية نتائج دقيقة في وقت قصير.

- **السكيلز اللي طبقتها فعليًا:** 
  - لغة Python
  - الذكاء الاصطناعي (AI)
  - الجبر الخطي وأساسيات الشبكات العصبية

- **حاجات جديدة اتعلمتها ملهاش دخل بالمنهج نفسه:**
  - تنظيم بنية المشروع البرمجي والتعامل مع واجهة الأوامر (CLI) بكفاءة لتشغيل السكريبتات وتمرير المتغيرات.

- **علاقات/شبكة تواصل استفدت منها:**
  - الـ Code Reviewers في يوداسيتي، الذين قدموا ملاحظات قيمة لتحسين كفاءة الكود المكتوب.

- **رابط الشهادة/الإثبات:**

- **ملاحظات حرة:**
